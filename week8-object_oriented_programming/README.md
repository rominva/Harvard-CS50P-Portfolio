# CS50P - Problem Set 8

Solutions for Problem Set 8 of **CS50's Introduction to Programming with Python** by Harvard University.

This problem set focuses on object-oriented programming, testing, date/time handling, and generating files with Python. :contentReference[oaicite:1]{index=1}

## Exercises

### 1. Seasons of Love 💘⏳

A program that calculates the number of minutes a person has lived based on their date of birth.

Concepts practiced:
- Working with `datetime` and `date`
- Parsing and validating dates
- Using external libraries (`inflect`) to convert numbers into words
- Writing reusable functions and tests

---

### 2. Cookie Jar 🍪

An implementation of a `Jar` class that simulates a cookie jar with a limited capacity.

Features:
- Store and track the number of cookies
- Add and remove cookies using class methods
- Validate capacity limits
- Use properties to control access to class attributes
- Raise appropriate errors for invalid operations

Concepts practiced:
- Object-oriented programming (OOP)
- Classes and methods
- Properties (`@property`)
- Exception handling

---

### 3. CS50 Shirtificate 👕

A program that generates a personalized CS50 shirtificate as a PDF file.

Features:
- Takes the user's name as input
- Creates an A4 portrait PDF
- Adds text and images using `fpdf2`
- Places the user's name on the shirt image

Concepts practiced:
- Working with external libraries
- PDF generation
- Image handling
- Formatting and positioning elements

---

## Technologies Used

- Python 3
- `datetime`
- `pytest`
- `inflect`
- `fpdf2`
